# Python More Data Structures

This project covers advanced data structures in Python, including:

- Sets and their methods
- Dictionaries and their usage
- Lambda functions
- Map, Reduce, Filter
- Iteration and comparison with lists

## Learning Objectives

At the end of this project, you will be able to:

- Explain why Python programming is awesome
- Understand and use sets and dictionaries
- Use lambda, map, reduce, and filter functions
- Decide when to use sets, dictionaries, or lists
