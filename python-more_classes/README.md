# Python More Classes

This directory contains exercises related to Object-Oriented Programming (OOP) in Python, focusing on creating and using classes, attributes, methods, and the Python object model.

## Learning Objectives

At the end of this project, you are expected to be able to explain:

- What is a class
- What is an object and an instance
- Difference between class and object
- What is an attribute
- How to define public, protected, and private attributes
- What is self
- How to define methods
- How to use __init__ for instantiation
- Pythonic way of using getters and setters
- Special methods like __str__, __repr__, and __dict__
- Class attributes vs instance attributes
- Class methods and static methods
- How to dynamically add attributes to instances and classes
- Using getattr() and attribute lookup
