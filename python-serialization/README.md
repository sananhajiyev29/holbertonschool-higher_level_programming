# Python Serialization

This directory contains exercises related to serializing and deserializing Python objects, including JSON file handling.

## Learning Objectives

- Understand basic serialization and deserialization
- Work with JSON files in Python
- Save Python dictionaries to JSON files
- Load JSON files back into Python dictionaries

## Requirements

- Use Python 3
- Only use built-in modules
- All files must have proper docstrings and be executable
